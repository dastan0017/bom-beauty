## What moved the numbers

The first run scored 80–84 with LCP around 4.6 s. The LCP element on every page is the H1 (Cormorant heading font).

| Change                                                                                              | Effect                           |
| --------------------------------------------------------------------------------------------------- | -------------------------------- |
| Logo PNGs resized from 1276×218 to 421×72 (3× the 24 px display height), palette-quantised          | 234 KB → 9 KB                    |
| Cormorant shipped as static weight-600 instances (the only weight headings use), trimmed features   | 170 KB → 70 KB of heading fonts  |
| No root `loading.tsx`: it wrapped pages in a Suspense boundary, so the H1 arrived in a hidden chunk | LCP ≈ FCP again (observed)       |
| `app/icon.png` / `apple-icon.png` from the brand flower mark                                        | no `/favicon.ico` 404 in console |

Pages render on the server in 15–45 ms (the API responses come from Next's data cache), and `<Link>` prefetches routes,
so navigation needs no skeleton screens.

## Re-run after media is uploaded

Photos will add an image request to most pages; the hero, program and product images are the likely new LCP elements.
`BbImage` serves AVIF/WebP variants with `srcset`, marks above-the-fold images `fetchpriority="high"`, and lazy-loads the
rest. Re-run this report once the owner has uploaded the real media.

```sh
pnpm --filter @bom/frontend build
cp -R frontend/.next/static frontend/.next/standalone/frontend/.next/static
cp -R frontend/public frontend/.next/standalone/frontend/public
(cd frontend/.next/standalone/frontend && PORT=3200 node --env-file=../../../../.env server.js) &
npx lighthouse@12.8.2 http://127.0.0.1:3200/ --only-categories=performance,accessibility,best-practices,seo
```
