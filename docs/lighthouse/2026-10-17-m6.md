## What changed in M6

| Change                                                                                                                                                                                     | Effect                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Site CSP added (`frontend/src/security-headers.ts`); zod's eval probe blocked by it was reported as a browser issue                                                                        | Best practices 96 → 100 after zod runs `jitless` in browsers              |
| `@bom/shared/web` (helpers without zod or phone parsing) for the site's client code; the order sheet loads after the page settles, its schema from `@bom/shared/forms`                     | First-load JS 305 → 166 KB gzipped on every page; the form's 134 KB later |
| Review slider dots and the product gallery dots became pointer shortcuts (as in the design); the currency button, hero photo link and review cards name what they show (WCAG 2.5.3, 2.5.8) | Accessibility stays 100 once reviews exist                                |

The LCP element is still the H1 in the heading font, and most of the LCP time is render delay while that font loads.
The order sheet's code arrives about 1.5 s after the `load` event as one ~140 ms task at Lighthouse's 4× CPU
slowdown, before anyone realistically taps "Заказать"; a tap that comes earlier loads it on the spot.
